# Каталог месторождений

Локальный веб-сервис для просмотра SHP/DBF и экспорта выбранных записей в
DBF-карточку настольной программы. Загруженный ZIP хранится в `data/deposits.zip`
и автоматически подключается при следующем запуске.

```bash
cd /home/dhh/Work/mpi
python3 -m venv .venv  # если окружение ещё не создано
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m app.main
```

Откройте `http://127.0.0.1:8000`. Чтобы открыть сервис другим компьютерам в
доверенной локальной сети, запустите его с `HOST=0.0.0.0`; тогда используйте
локальный IP компьютера с сервисом:

```bash
HOST=0.0.0.0 .venv/bin/python -m app.main
```

У сервиса нет авторизации — не открывайте
его в недоверенную сеть.

Загрузите ZIP с одним набором одноимённых `.shp` и `.dbf`; `.prj` нужен для
корректного отображения геометрии на карте. После загрузки запись можно скачать
отдельным DBF или экспортировать весь набор. В DBF используются поля карточки
настольной программы, кодировка Windows-1251.

## Развёртывание в Kubernetes

GitHub Actions запускает тесты и публикует контейнер `ghcr.io/drem-link/mpi_tfgii`
с тегами `latest` и `sha-*` при push в `main`. PDF, локальное окружение и
загруженный набор данных в репозиторий и контейнер не попадают.

После первой сборки сделайте пакет GHCR публичным в GitHub Packages, затем на
сервере примените манифест:

```bash
kubectl apply -f deploy/k8s/mpi.yaml
kubectl -n mpi-tfgii rollout status deployment/mpi
kubectl -n mpi-tfgii get service mpi
```

Сервис доступен на IP Kubernetes-узла и выделенном NodePort (посмотрите его в
выводе `get service`); разрешите этот TCP-порт в firewall. Загрузите ZIP-шейп
через интерфейс один раз: он хранится на PVC и переживает перезапуски pod.
После публикации нового образа перезапустите deployment, чтобы он скачал `latest`:

```bash
kubectl -n mpi-tfgii rollout restart deployment/mpi
```

PVC требует доступного в кластере StorageClass по умолчанию. Приложение не имеет
авторизации: ограничьте NodePort доверенной сетью и не публикуйте его в интернет
без прокси с HTTPS и защитой доступа.
